# BG Couriers for WooCommerce

A WordPress/WooCommerce shipping plugin for Bulgarian couriers — **Speedy, Econt,
BoxNow, and Pigeon Express** — shipping to Bulgaria. Lets customers pick a courier,
delivery type (address / office / automat), and destination at checkout with live
pricing, and lets admins generate shipping labels and track orders in one click.

> **Status:** design phase. See the design spec:
> [`docs/superpowers/specs/2026-06-21-bg-couriers-design.md`](docs/superpowers/specs/2026-06-21-bg-couriers-design.md).

## Scope

- **v1:** Speedy, end-to-end (checkout selection → live price → order → admin
  label → tracking).
- **Phase 2:** Econt, BoxNow, Pigeon adapters.
- Bulgaria-only destinations. Classic WooCommerce checkout. HPOS-compatible.
